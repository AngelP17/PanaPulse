## 1. Best approved visual design

v0.2 (`d5d0de1`) for atmosphere: saturated four-stop dusk sky (`#2C4266 → #47558A → #7A6C9C → #CB8B78` at night)
and borderless floating cards. `main` is the right base: B's information design inside v0.2's surfaces plus the
P brand. What `main` lost relative to v0.2 is sky richness (navy/cyan) and borderless depth (1px outline on every
card). Both are token or one-line fixes.

## 2. Later versions that added real value

- `recovery`: USGS ingest with revision hashing and snapshot dedupe; OAF aftershock forecast storage; guarded
  `/v0/ask` on Haiku 5.5 with per-minute, per-day and global budgets; instant deterministic answers;
  Naturgy/ENSA concession map; ENSA and Naturgy schedule parsers with `SourceFormatChanged`.
- `preview/b-refinement`: Mi zona, pulse rail, commute timeline with Google Maps hand-off, separate Luz and
  Agua cards, stale state, Mobility tab, bottom nav that never covers content.
- `main`: P brandmark, app icon, CI workflow (pytest + tsc), AGENTS.md, BRAND.md, non-destructive publish
  script, compiled Python removed from git.

## 3. Changes that reduced visual quality

- v0.3: flat, dense, generic. Parked.
- B and `main`: navy/cyan palette reads as AI-SaaS branding.
- `main`: `Card` got `borderWidth: 1` everywhere, flattening the floating depth.
- Luz/Agua cards: 12px uppercase pills ("DESACTUALIZADO", "SIN DATOS") and caption-size body copy. The
  contract bans tiny status pills.
- Nav: lucide `TrainFront` at 20px reads as a robot face.
- `app.json`: Android adaptive icon lost `monochromeImage` (themed icons on Android 13+) and `backgroundImage`.
- Header wordmark "Pana" + accent "Pulse" is the one-accented-word pattern. Brand-level, so flagged only.

## 4. Works today

- Live USGS events in the app (9 s timeout, dated snapshot fallback).
- USGS aftershock probabilities quoted verbatim with issue time and SINAPROC link. No app-side prediction.
- Chat: quick answers first, then Haiku with read-only tools (artifact sampler or backend).
- Power provider per corregimiento from official concession lists.
- es/en (typed parity), Auto/Light/Dark, persisted preferences, Android hardware back.
- Backend: idempotent ingest, revisions, rate limits, cost budget, 26 offline tests, CI.

## 5. Mocked, incomplete or disconnected

- Zone hardcoded to "Pueblo Nuevo": `Home.tsx` title and Maps link, `Report.tsx` default, `Chat.tsx`,
  `quick.ts` default.
- Commute is a fixed example (labeled "Ruta de ejemplo"). No saved journey.
- Power notices are a bundled snapshot (`utilities_snapshot.json`, Oct 12). No utilities endpoint; parsers never
  run against live pages.
- Water: no source. Metro/MiBus: no data, links only (correct, no open feed exists).
- Reports are local-only (AsyncStorage). No aggregation, so "¿Se fue solo a mí?" can't be answered.
- API exposes only `/v0/ask`, `/v0/forecast`, `/healthz`. No deployment, no ingest scheduler.
- State-based navigation, not Expo Router. No deep links.
- No native baseline screenshots. Tags `v0.2` and `v0.3-parked` not on GitHub (the session's git policy
  blocked tag pushes; run `git push origin --tags` locally).

## Roadmap

- **Phase 0, freeze visuals**: `feat/palette-tokens` (palette, mark, status colors, approved surface fixes, all
  four instruction docs); `chore/visual-baseline` (Home, Movilidad, Sismos, Reportes, Ajustes × light/dark).
- **Phase 1, foundation**: `refactor/expo-router` (tabs + modal Chat/Ajustes, must pixel-match baseline);
  `feat/my-zone`.
- **Phase 2, mobility**: saved home-to-work journey on the open-data Metro station list (dated 2022);
  every time labeled Programado / En vivo / No disponible; Google Routes transit test behind the backend with a
  monthly cap (verify the transit SKU first); GTFS/GTFS-RT request drafts to Metro de Panamá and MiBus for
  review before sending.
- **Phase 3, utilities**: run parsers live once; `/v0/utilities`, scheduler, freshness and revisions; app reads
  backend with snapshot fallback; IDAAN in the same framework; Agua Pa' Cuando outreach draft.
- **Phase 4, reports**: `/v0/reports` with one-tap flow, corregimiento-level location only, anonymous device
  key, rate limits, 30-minute dedupe, neighbor counts, deletion. Never green from absence of reports.
- **Phase 5, AI**: server-side notice extraction (parsers first, Haiku JSON validated against corregimientos and
  date ranges, cached by content hash, daily budget). Then visual regression on every PR.
