My pick

1 · Crepúsculo

A periwinkle sky that warms into a coral horizon, porcelain-tinted cards, and a storm-blue accent (periwinkle at night). It brings back the cool-to-warm dusk you liked in v0.2 and drops the navy/cyan AI-dashboard look. Coral stays in the sky and the mark, so it never competes with alerts.

The catch: these five candidate colors are close to v0.2's own gradient (steel blue, indigo, violet, coral), which was Hark's sunset. So Crepúsculo is the closest to Hark of the three. What keeps it PanaPulse is the P mark, the bottom nav, Mi zona and the pulse rail, not the gradient. If that bothers you, Tinta is the most distinct.

Repository audit

Read-only pass over every branch now on GitHub. Backend tests 26/26 and the TypeScript check both pass on main.

1Best approved visual design

v0.2 (v0.2-original, d5d0de1) for atmosphere: the saturated four-stop dusk gradient and borderless floating cards. main (50d7cd7) is the right baseline to build on: B's layout inside v0.2's surfaces, plus the P brand. The thing main lost compared with v0.2 is the richness of the sky and the borderless depth, and both are fixable with tokens.

2Later versions that added real value

  • recovery: USGS ingest with revisions, OAF aftershock forecasts, guarded /v0/ask (Haiku 5.5, rate limits, cost budget), instant answers, Naturgy/ENSA concession map, ENSA and Naturgy parsers.
  • preview/b-refinement: Mi zona, pulse rail, commute timeline, separate Luz and Agua cards, stale state, Mobility tab, bottom nav that never covers content.
  • main: P brandmark and app icon, CI (pytest and tsc), AGENTS.md, BRAND.md, safe publish script, compiled Python files removed from git.

3Changes that cost visual quality

  • v0.3: flat and dense. Parked on archive/v0.3-parked.
  • B, main: the navy/cyan palette.
  • main: a 1px outline on every card. It flattens the floating depth v0.2 had.
  • Luz and Agua cards: tiny uppercase pills ("DESACTUALIZADO", 12px) and caption-size body text. That's exactly the pattern the contract bans.
  • Nav: at 20px the Movilidad train icon reads like a robot face.
  • Android icon: main dropped the monochrome layer, so themed icons on Android 13+ fall back to a generic look.

4What works today

  • Live USGS quakes in the app (9s timeout, falls back to a dated snapshot).
  • USGS aftershock probabilities quoted verbatim, with issue time and SINAPROC link.
  • Chat: instant answers for common questions, then Haiku with read-only tools.
  • Correct power provider per corregimiento (Naturgy vs ENSA concession lists).
  • Spanish/English, Auto/Light/Dark, saved preferences, Android back button.
  • Backend: idempotent USGS ingest, snapshot dedupe, revision history, 26 offline tests.

5Mocked, incomplete or disconnected

  • Zone is hardcoded to Pueblo Nuevo in Home, Report, Chat and the instant answers. There's no picker.
  • The commute is a fixed example route (correctly labeled "Ruta de ejemplo"). No saved journey.
  • Power notices come from a bundled snapshot dated Oct 12. The backend has no utilities endpoint, and the parsers have never run against live ENSA/Naturgy pages.
  • Water: no source connected. Metro and MiBus: no data, only official links.
  • Reports stay on the phone (AsyncStorage). "¿Se fue solo a mí?" can't be answered yet.
  • The API only has /v0/ask, /v0/forecast and /healthz. No deployment, no ingest schedule.
  • Navigation is a state switch, not Expo Router. No deep links.
  • No native screenshots yet. The v0.2 and v0.3-parked tags aren't on GitHub (this session can't push tags).

6Reusable as is

Sky, Card (with featured), CardHeader, Tile/TileGrid, StatusChip, SourceLine, Button, Txt, PulseRail, PulseMark, Header, BottomNav, Composer, the quake detail sheet, format.ts (Panama time, no DST), typed i18n, chat engine, quick answers and tools. Backend: USGS ingest, utility adapters with SourceFormatChanged, RateLimiter, revision hashing, snapshot dedupe.

Roadmap

One focused branch per row, each with before/after screenshots against the baseline. Order follows your note: freeze visuals, mobility, utilities, reports, then AI.

Phase 0Freeze visuals
  • feat/palette-tokens: chosen palette, themed mark, status colors, the approved surface fixes, all four instruction docs updated together.
  • chore/visual-baseline: native Android screenshots of Home, Movilidad, Sismos, Reportes, Ajustes in light and dark, committed as the reference.
Phase 1Foundation
  • refactor/expo-router: tabs (Inicio, Movilidad, Sismos, Reportes), with Chat and Ajustes as modal routes. Pixel-match against the baseline, so no visible change is allowed.
  • feat/my-zone: saved corregimiento drives Home, Report, Chat and quick answers.
Phase 2Mobility
  • Saved home-to-work journey with Metro L1/L2 stations from the open-data station list (labeled with its 2022 date).
  • Every time shows one of three labels: Programado, En vivo, No disponible. Today nearly everything is No disponible, and that's correct.
  • Google Routes transit test on the backend with a monthly cap. Billing tier for transit mode is unverified, so I'll check it before any code.
  • Draft emails to Metro de Panamá and MiBus asking for GTFS / GTFS-RT, for you to review and send.
Phase 3Utilities
  • Run the ENSA/Naturgy parsers against live pages once on your machine. Then add /v0/utilities, a schedule, freshness and revision tracking. The app reads the backend and falls back to its dated snapshot.
  • IDAAN notices in the same adapter framework. Draft an outreach note to Agua Pa' Cuando about a read-only feed.
Phase 4Reports
  • /v0/reports: one-tap "¿Se fue solo a mí?", corregimiento-level location only, anonymous device key, rate limits, 30-minute dedupe, "N vecinos reportaron" aggregates, and clear data deletion.
Phase 5AI
  • Server-side extraction for free-text notices (IDAAN posts, PDF schedules). Parsers run first. Haiku returns JSON that's checked against the corregimiento list and date ranges, cached by content hash, under a daily budget. Chat stays read-only and grounded.
  • Then the visual regression suite runs on every PR against the Phase 0 baseline.
